# Security Policy

## Supported Versions

Lith is currently in active development. Security updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Lith seriously. If you discover a security vulnerability, please report it responsibly rather than opening a public issue.

### Disclosure Process

1. **Reporting**: Send details of the security vulnerability via private security advisory on GitHub or directly to project maintainers.
2. **Details to include**:
   * Description of the vulnerability and potential impact.
   * Steps to reproduce the issue (proof of concept code or configuration).
   * Affected components or versions.
3. **Response**: We will acknowledge receipt of your report within 48 hours and provide status updates as we investigate and address the issue.
4. **Resolution**: Once a fix is verified, a patch will be committed and a advisory published in accordance with coordinated disclosure practices.

Thank you for helping keep Lith and its community safe!
